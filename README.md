# 🎂 Birthday v8 ✨

An interactive, romantic web animation celebration designed with HTML5 Canvas, modern CSS animations, and pure JavaScript.

---

## 💖 Features

- 🎆 **Romantic Firework Explosions**: Fireworks launch from the center, bursting with shimmering particle sparks and blooming into birthday text.
- 🎨 **Romantic Color Palette**: Letters and firework shards cycle through glowing shades of rose pink, ruby red, soft blush, warm gold, magenta, coral, and deep crimson.
- 🎈 **Glowing Balloons**: Letters transform into glowing balloons with soft pulsating neon shadows that drift upwards into the dark sky.
- 🖤 **Pure Black Backdrop**: High-contrast, pitch-black canvas background (`#000000`) for maximum visual pop and romantic atmosphere.
- 💌 **Interactive Floating Letter**:
  - **1st Click**: Jumps to a new random spot on screen with a pop animation.
  - **2nd Click**: Jumps to another random location.
  - **3rd Click**: Opens an elegant, glowing romantic birthday message card modal.
- 📱 **Fully Responsive**: Adapts smoothly to all screen sizes, from mobile phones to ultra-wide displays.

## 🚀 How to Run

1. Clone or download this repository.
2. Open `Birthday.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. No build steps, dependencies, or local web servers required!

---

## 🛠️ Built With

- **HTML5** & **Canvas API** — Particle physics, text rendering, and fireworks animation
- **CSS3** — Keyframe animations, backdrop blur, and neon glow effects
- **JavaScript (Vanilla)** — Dynamic particle simulation and click interaction
